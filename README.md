# AlSibir — сайт с интегрированной графикой

## Состав

`dist/` — готовый статический сайт для GitHub Pages по адресу https://alsibir.github.io/alsibir-expert/. `src/` — исходники Astro/Starlight. `public/` — файлы, копируемые в корень сборки. `images/` — сохранённые исходные большие иллюстрации. `node_modules/` и служебные кэши не включены: они зависят от ОС и восстанавливаются через npm ci.

## Первый просмотр

1. Распаковать весь архив.
2. Linux: `bash start-preview-linux.sh`; Windows с Python: запустить `start-preview-windows.cmd`.
3. Открыть http://127.0.0.1:8080/alsibir-expert/. Остановить сервер сочетанием Ctrl+C.

Открытие dist/index.html двойным щелчком не заменяет HTTP-сервер: ссылки сайта начинаются от корня. Скрипты только запускают локальный сервер; не устанавливают Python и не публикуют сайт.

## Расположение материалов

| Назначение | Исходники | Адрес в готовом сайте |
|---|---|---|
| Большие изображения двух тем | public/images/light и public/images/dark | /images/light и /images/dark |
| Логотипы, значки, пиктограммы | public/img | /img |
| Резюме | public/CV | /CV/alexander-sibiryakov-cv.pdf |
| Пять PDF-примеров и ZIP | public/examples | /examples |
| Реальные страницы документов | public/images/evidence | /images/evidence |

Принятые иллюстрации сохранены в обоих вариантах подключения без изменения сюжета и внешности. Светлая и тёмная темы используют одну утверждённую цветовую обработку, а фон и элементы интерфейса меняются средствами CSS.

## Что подключено

Общие компоненты Header, Footer, SiteTitle, Head, Hero и PageTitle. Логотип в обеих темах, четыре пиктограммы компетенций, навигация, ссылки на скачивание, электронную почту и карту сайта. Главное изображение — портрет. Крупные иллюстрации назначены по назначению разделов и темам статей. Карточки реальных работ и PDF отделены от учебных кейсов. Показатели приведены по сведениям автора в резюме.

Все изображения имеют alt; для декоративных элементов он пустой. Изображения содержательных схем доступны по ссылкам в портфолио с указанием страницы оригинала. Заголовки и кнопки остаются текстовыми. Исправлены дублирующие H1 и отсутствовавший title статьи «Мои команды».

## Пересборка

Node.js 22.12+; рекомендуется актуальная Node.js 24 LTS. В каталоге проекта:

```bash
npm ci
npm run build
```

Адрес сайта закреплён в astro.config.mjs: https://alsibir.github.io/alsibir-expert/; base: /alsibir-expert. Переменная SITE_URL не требуется. Команда npm run build автоматически формирует XML-карту, абсолютные адреса превью и корректирует локальные ссылки для подкаталога GitHub Pages. Результат корректировки включён в dist.

## Размещение

1. При необходимости выполнить npm ci и npm run build.
2. Разместить содержимое dist/ в источнике публикации GitHub Pages репозитория alsibir/alsibir-expert. Исходники Astro не заменяют готовую сборку.
3. Настроить выдачу dist/404.html для неизвестных адресов средствами хостинга.
4. Проверить переключение темы, поиск, скачивание резюме и примеров.

Папка public/ не должна добавляться в публичные URL. Комплект рассчитан на подкаталог /alsibir-expert/. Для другого адреса требуется изменить site, base и настройки scripts/postbuild.mjs.
