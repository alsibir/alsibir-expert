# Старый адрес сайта АПС

Основной сайт: https://alsibir.github.io/aps-expert/.

Репозиторий сохраняет переходы со старых страниц и доступ к ранее опубликованным файлам. Исходники основного сайта находятся в https://github.com/alsibir/aps-expert.

GitHub Pages: Deploy from a branch → main → /(root).

Workflow refresh-redirects формирует совместимый сайт из зафиксированного коммита основного проекта. Для обновления следует изменить ref на проверенный коммит и запустить workflow.
