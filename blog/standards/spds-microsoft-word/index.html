Как оформить документ по СПДС в Microsoft Word

Дата публикации: 20 мар. 2024 г.

Оформление документации по СПДС в Microsoft Word требует решить задачу, которая значительно сложнее обычной верстки текстового документа. В одном файле Word могут последовательно размещаться несколько самостоятельных документов, каждый из которых имеет собственную нумерацию листов, заглавный лист, последующие листы, основную надпись и внутреннее оглавление. Одновременно весь том должен оставаться единым документом со сквозной структурой и корректным содержанием.

Для решения этой задачи достаточно штатных средств Microsoft Word:

  • разделов документа;
  • разрывов разделов;
  • колонтитулов;
  • закладок;
  • полей Word;
  • вычисляемых полей;
  • свойств документа;
  • стилей заголовков;
  • автоматического оглавления.

Главный принцип состоит в том, что структура документа сначала формализуется средствами Word, после чего номера листов, количество листов, ссылки и повторяющиеся реквизиты выводятся автоматически.

1. Структура тома СПДС

Заголовок раздела «1. Структура тома СПДС»

Том проектной документации не следует рассматривать как один непрерывный текстовый документ.

Внутри одного файла могут находиться, например:

  1. титульный лист тома;
  2. содержание тома;
  3. состав проектной документации;
  4. пояснительная записка;
  5. описание технических решений;
  6. спецификация;
  7. приложения;
  8. иные самостоятельные документы.

Каждый такой документ может иметь собственную нумерацию листов.

При этом физически все документы находятся в одном файле Word.

Поэтому в документе одновременно существуют две системы координат:

физическая страница файла Word — положение страницы относительно начала всего файла;

лист самостоятельного документа — номер листа внутри конкретного документа СПДС.

Например, пояснительная записка может физически начинаться на 12-й странице тома, но в ее основной надписи эта страница должна отображаться как лист 1.

Именно для решения этой задачи используются разделы Word, закладки и вычисляемые поля.

2. Разделы Word

Заголовок раздела «2. Разделы Word»

Каждый самостоятельный документ рекомендуется начинать с нового раздела Word.

Для этого перед началом документа устанавливается:

Макет → Разрывы → Разрывы разделов → Со следующей страницы.

Упрощенная структура может выглядеть следующим образом:

Разделы необходимы прежде всего для независимого управления:

  • колонтитулами;
  • основными надписями;
  • ориентацией страниц;
  • размером листа;
  • различием первого и последующих листов;
  • другими параметрами страницы.

При этом не следует считать, что один документ СПДС всегда соответствует строго одному разделу Word.

Например, внутри пояснительной записки может потребоваться:

  • альбомный лист;
  • лист формата А3;
  • отдельный колонтитул;
  • изменение полей страницы.

Для этого внутри одного документа СПДС создаются дополнительные разделы.

Следовательно, номер документа и номер раздела Word — разные понятия.

10. Первый и последующие листы

Заголовок раздела «10. Первый и последующие листы»

Для текстовых документов СПДС оформление первого листа и последующих листов различается.

В Word это удобно реализовать через параметр:

Особый колонтитул для первой страницы.

Для раздела документа создаются:

  • колонтитул первой страницы;
  • колонтитул последующих страниц.

На первом листе размещается соответствующая основная надпись первого листа.

На последующих листах — основная надпись последующих листов.

Рамка и основная надпись обычно размещаются в колонтитулах, поскольку это позволяет:

  • сохранять их положение относительно края страницы;
  • исключить смещение при редактировании текста;
  • использовать разные формы для первой и последующих страниц;
  • независимо управлять разными разделами документа.

11. Связь колонтитулов разделов

Заголовок раздела «11. Связь колонтитулов разделов»

После создания нового раздела Word его колонтитул по умолчанию может быть связан с предыдущим.

Для самостоятельных документов эту связь необходимо контролировать.

Используется команда:

Конструктор колонтитулов → Как в предыдущем разделе.

Если новый документ должен иметь собственную основную надпись, связь с предыдущим разделом отключается.

Особое внимание требуется при:

  • начале нового документа;
  • переходе А4 → А3;
  • изменении ориентации;
  • возврате А3 → А4.

Неправильно установленная связь может привести к изменению основной надписи сразу в нескольких частях тома.

Работу целесообразно выполнять в следующем порядке:

  1. Определить состав тома.
  2. Определить самостоятельные документы.

  7. Настроить первую и последующие страницы.

  9. Вставить вычисляемые номера листов.
  10. Вставить вычисляемое количество листов.
  11. Создать свойства документа для повторяющихся реквизитов.
  12. Применить стили заголовков.
  13. Сформировать содержание тома.
  14. Сформировать локальные оглавления.
  15. Обновить все поля.
  16. Проверить документ в режиме отображения кодов полей.
  17. Выполнить финальную проверку после преобразования в PDF.

26. Итоговый принцип

Заголовок раздела «26. Итоговый принцип»

Основные элементы этой структуры:

В результате изменение объема текста, добавление страниц, вставка листов А3 или изменение состава тома не требуют ручного перенумерования всех последующих документов.
