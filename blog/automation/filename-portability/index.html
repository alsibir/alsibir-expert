Имена файлов, совместимые с Windows и Linux

Дата публикации: 25 нояб. 2024 г.

Условная дата: хронология этой статьи синтезирована для демонстрации сайта. Не подтверждает фактическую дату написания или публикации.

В проектах, которые перемещаются между Windows, Linux и USB-носителями, имена файлов влияют на надёжность сборки и ссылок.

Практические правила

Заголовок раздела «Практические правила»
  • Для технических идентификаторов использовать строчные латинские буквы, цифры и дефисы.
  • Не создавать имена, различающиеся только регистром символов.
  • Избегать специальных символов <>:"/\|?*, пробелов в конце имени и зарезервированных имён Windows.
  • Не использовать слишком длинные пути и нестабильные временные имена.
  • Для URL выбирать предсказуемые slug, независимые от отображаемого русского заголовка.

Пример: requirements-traceability.md надёжнее, чем файл со случайными пробелами и смешанным регистром. После переименования обязательно проверять ссылки и выполнять сборку проекта.
