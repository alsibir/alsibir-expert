# Внутренние материалы АПС

Каталог хранится в корне репозитория, вне `src/content/docs` и `public`. Его содержимое не должно включаться в сборку GitHub Pages, меню, поиск, RSS и карту сайта.

Перенесены 5 ноября 2026 года:

- `blog/tools/APS_ChatGPT_Figma_Design_Guide.md` — внутреннее задание на оформление сайта и запросы для Figma.
- `blog/tools/my-commands-linux-mint.md` — сценарии сопровождения личного рабочего окружения и сайта АПС.
- `blog/security/03_anonimizer_engineering_article.md` — проект статьи с редакционными указаниями и неподтверждёнными сведениями о реализации и испытаниях.

Связанные установочные архивы и инструкции «Мои команды» сохранены в `assets` с исходными путями. Исходные тексты сохранены без изменений. Прежние адреса перечислены в `manifest.json` для проверки отсутствия в сборке.

Каталог не является разделом сайта: адрес `/alsibir-expert/4APS/` не публикуется. Материалы доступны владельцу через исходный репозиторий. Публичность самого GitHub-репозитория этим переносом не изменяется.
