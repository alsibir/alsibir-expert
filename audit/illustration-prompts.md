# Единый стиль схем и промпты

Целевые схемы Заказчика не получены. Файлы public/images/concepts — концепции, не утверждённые архитектуры; на действующих страницах не подключены. Текущие карточки testing и clear-tz показывают общие темы и не раскрывают алгоритмы. Документальные карточки evidence сохранены.

Референсы: https://nanosemantics.ai/customers/20 и https://nanosemantics.ai/dialog-os. Последний — диалоговая платформа, не источник об архитектуре ОРФО. Источник ОРФО необходимо уточнить; связь ОРФО с DialogOS не предполагается.

Стиль: плоские блоки, фон #f5eee9, контуры #80503b, текст #22212e, одинаковая сетка, стрелки с направлением, минимум декора. Кириллица — редактируемый текст SVG; содержательные схемы выполнять кодом, а не генератором изображений.

Промпт ОРФО: «После получения подтверждённой схемы представить обработку текста: ввод, анализ, предложения исправлений, решение пользователя, результат. Указать фактические названия модулей только из исходных данных. Отметить неподтверждённые связи. Не добавлять серверы, модели и API предположительно».

Промпт Снежинка: «На основе предоставленной схемы показать посетителя, сенсорный ввод и голосовой канал, приложение стенда, диалоговую обработку и вывод цифрового аватара. Отдельно обозначить аппаратные компоненты, если их связи подтверждены. Не представлять концепцию как фактическую инфраструктуру. Подпись: Источник — проект Наносемантики, https://nanosemantics.ai/customers/20».

Общий промпт для ИИ-иллюстратора: «Создать декоративную иллюстрацию для технического сайта в тёплой терракотово-графитовой палитре, без текста и без вымышленных технических связей; подписи и стрелки будут добавлены отдельно в SVG». Три пустых растра заменены исправными версиями другой темы или фрагментом PDF; апскейлинг не выполнялся. Для будущего восстановления сначала использовать оригинал из ___ФОТКИ или архива, затем осторожный апскейлинг без изменения лиц и документальных фрагментов.
