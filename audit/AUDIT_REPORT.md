# Технический и визуальный аудит alsibir-expert

Дата: 01.11.2026. Исходник: alsibir-expert-011126.zip. Прямого доступа к /media/ex1 нет.

## Выполнено

- Проверена структура Astro/Starlight, package-lock и существующий репозиторий alsibir/alsibir-expert.
- Исходный архив сохранён без изменений; в локальном Git создан полный backup/pre-cleanup. В публичный Git передаются рабочие исходники, а не старые архивы и фотографии. Удалённая backup/pre-cleanup сохраняет прежнюю историю GitHub и импорт действующих исходников из архива. Сгенерированные дубликаты, старые архивы и исходные фотографии остаются только в полном исходном архиве.
- Подтверждённые сгенерированные файлы, побайтовые дубликаты public и служебные desktop.ini перемещены в СТОРОННЕЕ. Удаление не выполнялось. Перемещённые файлы исключены из Git и сборки.
- Обнаружены и заменены 3 пустых WebP. Исправлен двойной базовый путь favicon на всех страницах.
- Извлечены 7 цветов фотографии; реализована тёплая схема акцентов, сохранены классы и действующие страницы.
- Созданы 2 предварительные SVG-схемы и промпты. Они не подключены вместо документальных свидетельств до получения целевых схем.
- Меню сокращено и сделано раскрываемым до 1100 px, размеры текста 15–16 px. Перенос самих пунктов исключён; двухполосная шапка сохранена.
- Добавлены ссылки на исходный проект Наносемантики в страницы с упоминанием Снежинки. Отнесение ОРФО к DialogOS не предполагается.
- Подготовлены кандидаты внутренних ссылок методом TF-IDF и отдельный патч для согласования. Тексты статей автоматически не перелинкованы.
- Workflow: PR — build и staging-static artifact; main — build, gh-pages и официальный Pages deploy. ZIP примеров воспроизводится из PDF при сборке с помощью Python 3.

## Проверки

npm ci и npm run build выполнены успешно, 188 страниц. scripts/audit.py проверил 25 153 локальных URL, ошибок нет. Проверяются href/src/poster и наличие alt; CSS url(), srcset и внешние URL этим скриптом не проверяются. Фрагменты #якорь отдельно проверены scripts/audit-anchors.py; ошибок нет. Все растровые public/images проверены Pillow, все SVG — XML-парсером. YAML workflow разобран PyYAML; это не заменяет выполнения Actions и actionlint.

Браузер: главная открыта в светлой и тёмной темах. При ширине 1363 CSS px меню расположено на одной строке, горизонтального переполнения страницы нет. Видимые изображения первого экрана загружаются. Полная матрица мобильных экранов и всех статей не проверена. Снимки использованы для внутренней проверки, в комплект не включены.

## Ограничения релиза

Окончательные схемы Заказчика не получены; техническая архитектура ОРФО не подтверждена. Нужен редакторский просмотр предложенных перекрёстных ссылок, проверка мобильного меню и итогового PR. До слияния в main автоматический production deploy не запускается. Проверочный artifact — не постоянно доступный staging-сервер.

Исходные страницы nanosemantics.ai проверены: https://nanosemantics.ai/customers/20 и https://nanosemantics.ai/dialog-os. Их содержимое не подтверждает архитектуру ОРФО. Точное соответствие шрифтов и цветовых кодов бренду не заявляется: реализована собственная палитра по портрету.
