# Алгоритм предложения внутренних ссылок

1. Обойти Markdown/MDX в src/content/docs; использовать заголовок title и актуальный текст статьи.
2. Исключить frontmatter, блоки кода, теги и URL. Разбить русский и английский текст на слова длиной от 4 символов. Текущая реализация не выполняет лемматизацию: это ограничивает полноту поиска русских словоформ.
3. Рассчитать частоту термина в документе и обратную частоту по корпусу: вес = частота × ln((1 + число документов) / (1 + число документов с термином)).
4. Рассчитать косинусную близость пар. Для каждой статьи выбрать до двух кандидатов с оценкой не ниже 0,18. Результат — audit/internal-links.json и таблица в TRASH_REPORT.md. Численная оценка не является вероятностью релевантности.
5. Выполнить редакторский проход по сущностям: конкретный стандарт, продукт, инструмент, процесс. Не связывать статьи только из-за общих слов «документ», «система», «работа». Не создавать ссылку на саму статью и циклические цепочки без пользы читателю.
6. После согласования добавить 1–2 ссылки в раздел «Связанные материалы» либо в подходящее первое упоминание. Не изменять код, заголовки, URL, существующие ссылки и примеры команд. Собрать сайт и проверить файлы, якоря, базовый путь.

## Промпт редактору

«Проанализировать исходную статью и список кандидатов с их заголовками и текстами. Для каждого кандидата указать общую сущность, конкретную пользу перехода и точное место вставки. Сохранять только подтверждённые связи. Если материалов недостаточно, не предполагать содержание по одному заголовку. Подготовить unified diff: не более двух новых внутренних ссылок на статью, без изменения технических фактов и команд. Сначала выдать таблицу на согласование; внедрять только одобренные ссылки».

## Применение подготовленного патча

Патч соответствует текущей редакции статей на дату аудита и добавляет разделы «Связанные материалы». До применения просмотреть кандидатов и исключить повторы разделов.

```bash
git apply --check audit/proposed-internal-links.diff
git apply audit/proposed-internal-links.diff
npm run build
python3 scripts/audit.py
python3 scripts/audit-anchors.py
```

Если git apply --check сообщает о несовпадении контекста, остановиться и пересформировать патч по актуальному исходнику. Автоматическое угадывание строк не допускается.
