Материалы специально разработаны автором для демонстрации профессиональных компетенций. Использованы условные продукты, системы и исходные данные. Документы заказчиков и конфиденциальные сведения в демонстрационные материалы не включены.

**Тип проекта:** демонстрационная модель обработки заявок.

## Исходная ситуация

Условная система принимает заявки, проверяет заполненность, передаёт их на рассмотрение и формирует уведомления. Термины, роли и исключения первоначально не описаны.

## Рабочие артефакты

| Артефакт | Что фиксируется |
|---|---|
| Контекст | Пользователи, внешние системы и границы |
| Use Case | Основной сценарий, альтернативы, ошибки |
| Модель данных | Заявка, статус, автор, история изменений |
| API-контракт | Операции, запросы, ответы, ошибки |
| Матрица проверки | Каждое требование и соответствующий тест |

В демонстрационном примере можно проследить, как требование «нельзя обработать неполную заявку» превращается в проверяемое правило и тест. Это **не описание внедрённой системы**.
