**Назначение:** единый источник реквизитов для заявления, ПМИ и документации.

| Параметр | Учебное значение | Статус |
|---|---|---|
| Наименование | Контур-Монитор | Утверждено только для кейса |
| Версия | 1.0.0 | Учебная конфигурация |
| Клиентская часть | Браузерный интерфейс | Требует уточнения списка браузеров |
| Сервер приложений | Учебный сервер приложений | Технология не установлена |
| СУБД | Не определена | Не указывать фиктивную поддержку |
| ОС серверная | Не определена | Нет протокола совместимости |
| ОС клиентская | Не определена | Нет протокола совместимости |
| Лицензия | Условная лицензия на экземпляр | Нужна юридическая модель |
| Порт подключения | Не определён | Требуется конфигурация стенда |
| Сборка / хэш | Нет исполняемого дистрибутива | Не присваивать искусственный хэш |

### Правило управления изменениями

Любое изменение версии, перечня зависимостей, допустимых ОС или лицензии в первую очередь регистрируется в паспорте. Затем проверяются описание функций, архитектура, инструкция, ПМИ и заявление. До завершения сверки состояние материалов — «Требует актуализации».

### Граница демонстрации

Техническая схема в статье — **проектная модель**, а не снимок проверенной работающей среды.
