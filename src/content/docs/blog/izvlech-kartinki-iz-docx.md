Изображение, вставленное в документ Word, не обязательно нужно сохранять через контекстное меню. Если файл имеет формат `.docx`, можно открыть его как ZIP-архив и извлечь медиаданные непосредственно из структуры документа. Такой способ удобен, когда требуется получить сразу десятки картинок.

Важно учитывать: внутри DOCX находятся **файлы, записанные в документ**, но их качество зависит от того, были ли изображения сжаты или изменены при сохранении. Этот метод не восстанавливает исходную фотографию, если Word уже уменьшил её разрешение.

## Способ 1. Извлечение через 7-Zip

1. Создать копию документа, чтобы не изменять оригинал.
2. Установить [7-Zip](https://www.7-zip.org/) или использовать уже имеющуюся версию программы.
3. Щёлкнуть по документу правой кнопкой мыши и выбрать открытие через архиватор 7-Zip.
4. Перейти в папку `word/media` внутри архива.
5. Выделить нужные файлы и нажать «Извлечь».
6. Сохранить изображения в отдельный каталог.

Внутри папки могут находиться файлы `image1.png`, `image2.jpeg` и другие. Имена часто не совпадают с названиями рисунков в тексте, поэтому после извлечения их нужно просмотреть.

## Способ 2. Переименование DOCX в ZIP

Если отдельный архиватор не используется, пригодится штатное открытие ZIP-архивов в Windows.

1. В Проводнике включить отображение расширений имён файлов.
2. Скопировать исходный документ, например `report.docx`.
3. Переименовать **копию** в `report.zip` и подтвердить изменение расширения.
4. Открыть ZIP-файл средствами Проводника.
5. Перейти в `word/media` и скопировать изображения в другую папку.

Если после переименования файл не открывается, проверьте, что он действительно имеет формат DOCX, а не старый DOC с вручную изменённым расширением. Простое переименование не преобразует один формат в другой.

## Способ 3. Извлечение в Linux

В Linux Mint, Ubuntu и других дистрибутивах DOCX можно открыть штатным архиватором или выполнить команду:

```bash
unzip -j 'report.docx' 'word/media/*' -d ./docx-images
```

Команда записывает файлы из папки `word/media` в `docx-images` без сохранения вложенной структуры. Если каталог уже содержит файлы с теми же именами, потребуется разрешить конфликт перезаписи. Для безопасной работы лучше предварительно создать пустой каталог.

Для просмотра содержимого без извлечения используется команда:

```bash
unzip -l 'report.docx' | grep 'word/media/'
```

## Как устроен документ DOCX

Формат DOCX относится к семейству Office Open XML. Физически он представляет собой ZIP-контейнер с XML-документами, служебными файлами и вложенными ресурсами. В архиве обычно встречаются:

| Путь | Назначение |
| --- | --- |
| `word/document.xml` | Основное содержимое документа |
| `word/styles.xml` | Определения стилей |
| `word/media/` | Изображения и некоторые другие медиаресурсы |
| `word/_rels/` | Связи элементов и вложенных ресурсов |
| `[Content_Types].xml` | Сведения о типах частей пакета |

**Осторожно:** редактирование этих XML-файлов вручную может повредить документ. Для извлечения картинок изменять внутреннюю структуру не нужно.

## Чем отличается старый DOC

Файлы `.doc` обычно используют двоичный контейнер OLE Compound File, поэтому открыть их как обычный ZIP-архив нельзя. Для работы с ними можно сначала сохранить копию в формате DOCX через Word или LibreOffice, а затем применить описанный способ. После преобразования стоит проверить, что все изображения присутствуют и не ухудшилось качество.

## Почему картинка не нашлась в word/media

Причины могут быть разными: изображение вставлено как внешний связанный объект, находится в другом компоненте пакета, было заменено объектом другого типа или исходный файл повреждён. В таких случаях можно попробовать экспорт документа в HTML, открыть вложенный объект в исходной программе или использовать специальный инструмент извлечения ресурсов.

## Итог

Для массового извлечения изображений из DOCX обычно достаточно 7-Zip или стандартного архиватора. Предпочтительно работать с копией документа, а после извлечения проверить имена, размеры и разрешение полученных файлов.
