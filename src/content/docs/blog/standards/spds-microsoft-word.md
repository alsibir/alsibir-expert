Оформление документации по СПДС в Microsoft Word требует решить задачу, которая значительно сложнее обычной верстки текстового документа. В одном файле Word могут последовательно размещаться несколько самостоятельных документов, каждый из которых имеет собственную нумерацию листов, заглавный лист, последующие листы, основную надпись и внутреннее оглавление. Одновременно весь том должен оставаться единым документом со сквозной структурой и корректным содержанием.

Для решения этой задачи достаточно штатных средств Microsoft Word:

- разделов документа;
- разрывов разделов;
- колонтитулов;
- закладок;
- полей Word;
- вычисляемых полей;
- свойств документа;
- стилей заголовков;
- автоматического оглавления.

Главный принцип состоит в том, что структура документа сначала формализуется средствами Word, после чего номера листов, количество листов, ссылки и повторяющиеся реквизиты выводятся автоматически.

## 1. Структура тома СПДС

Том проектной документации не следует рассматривать как один непрерывный текстовый документ.

Внутри одного файла могут находиться, например:

1. титульный лист тома;
2. содержание тома;
3. состав проектной документации;
4. пояснительная записка;
5. описание технических решений;
6. спецификация;
7. приложения;
8. иные самостоятельные документы.

Каждый такой документ может иметь собственную нумерацию листов.

При этом физически все документы находятся в одном файле Word.

Поэтому в документе одновременно существуют две системы координат:

**физическая страница файла Word** — положение страницы относительно начала всего файла;

**лист самостоятельного документа** — номер листа внутри конкретного документа СПДС.

Например, пояснительная записка может физически начинаться на 12-й странице тома, но в ее основной надписи эта страница должна отображаться как лист 1.

Именно для решения этой задачи используются разделы Word, закладки и вычисляемые поля.

## 2. Разделы Word

Каждый самостоятельный документ рекомендуется начинать с нового раздела Word.

Для этого перед началом документа устанавливается:

**Макет → Разрывы → Разрывы разделов → Со следующей страницы.**

Упрощенная структура может выглядеть следующим образом:

```text
Титульный лист

Разрыв раздела

Содержание тома
s1
...

Разрыв раздела

Состав проектной документации
s2
...

Разрыв раздела

Пояснительная записка
s3
...

Разрыв раздела

Описание технических решений
s4
...

Разрыв раздела

Спецификация
s5
...
```

Разделы необходимы прежде всего для независимого управления:

- колонтитулами;
- основными надписями;
- ориентацией страниц;
- размером листа;
- различием первого и последующих листов;
- другими параметрами страницы.

При этом не следует считать, что один документ СПДС всегда соответствует строго одному разделу Word.

Например, внутри пояснительной записки может потребоваться:

- альбомный лист;
- лист формата А3;
- отдельный колонтитул;
- изменение полей страницы.

Для этого внутри одного документа СПДС создаются дополнительные разделы.

Следовательно, номер документа и номер раздела Word — разные понятия.

## 3. Закладки начала документов

Для определения границ самостоятельных документов используются закладки Word.

В рассматриваемой структуре применяются закладки:

```text
s1
s2
s3
s4
s5
```

Закладка обозначает начало соответствующего документа.

Например:

```text
s1 — Содержание тома
s2 — Состав проектной документации
s3 — Пояснительная записка
s4 — Описание технических решений
s5 — Спецификация
```

Количество закладок может быть увеличено:

```text
s6
s7
s8
...
```

### Где устанавливать закладку

Закладку рекомендуется устанавливать в начале первого абзаца соответствующего документа.

Схема:

```text
[начало документа]
s1
СОДЕРЖАНИЕ ТОМА
...

[разрыв раздела]

s2
СОСТАВ ПРОЕКТНОЙ ДОКУМЕНТАЦИИ
...

[разрыв раздела]

s3
ПОЯСНИТЕЛЬНАЯ ЗАПИСКА
...
```

Закладку не требуется помещать непосредственно в символ разрыва раздела.

Практически надежнее установить ее в начале первого абзаца после разрыва.

### Создание закладки

1. Установить курсор в начало первого абзаца документа.
2. Выбрать **Вставка → Закладка**.
3. Ввести имя, например:

```text
s3
```

4. Нажать **Добавить**.

Имена закладок должны быть уникальными.

## 4. Поля Word

Основная автоматизация выполняется полями Word.

Особенно важны следующие поля:

```text
PAGE
PAGEREF
NUMPAGES
SECTIONPAGES
IF
DOCPROPERTY
TOC
```

Для работы с полями полезно знать стандартные сочетания клавиш Word:

- `Ctrl+F9` — создать настоящее поле Word;
- `F9` — обновить выделенное поле;
- `Shift+F9` — показать или скрыть код выбранного поля;
- `Alt+F9` — показать или скрыть коды всех полей документа;
- `Ctrl+A`, затем `F9` — обновить поля документа.

Фигурные скобки поля нельзя вводить с клавиатуры обычными символами `{` и `}`.

Например, поле

```text
{ PAGE }
```

должно быть создано средствами Word.

## 5. Сквозной номер страницы

Физический номер страницы текущего файла определяется стандартным полем:

```text
{ PAGE }
```

Если нумерация страниц Word не перезапускается между самостоятельными документами, это поле фактически содержит сквозной номер страницы тома.

Например:

```text
1
2
3
4
5
...
17
18
19
```

Это значение удобно использовать как основу для вычисления локального номера листа каждого документа.

## 6. Локальная нумерация листов

Предположим, пояснительная записка начинается с закладки:

```text
s3
```

Номер страницы, на которой находится эта закладка, можно получить полем:

```text
{ PAGEREF s3 }
```

Если пояснительная записка начинается на физической странице 12, результат будет равен:

```text
12
```

На первой странице пояснительной записки:

```text
PAGE = 12
PAGEREF s3 = 12
```

Следовательно:

```text
12 - 12 + 1 = 1
```

На следующей странице:

```text
13 - 12 + 1 = 2
```

Поэтому локальный номер листа рассчитывается формулой:

```text
{ = { PAGE } - { PAGEREF s3 } + 1 }
```

Для остальных документов применяются аналогичные формулы.

Для документа `s1`:

```text
{ = { PAGE } - { PAGEREF s1 } + 1 }
```

Для документа `s2`:

```text
{ = { PAGE } - { PAGEREF s2 } + 1 }
```

Для документа `s3`:

```text
{ = { PAGE } - { PAGEREF s3 } + 1 }
```

Для документа `s4`:

```text
{ = { PAGE } - { PAGEREF s4 } + 1 }
```

Для документа `s5`:

```text
{ = { PAGE } - { PAGEREF s5 } + 1 }
```

Таким способом локальная нумерация не зависит от количества предыдущих документов.

## 7. Почему не следует перезапускать PAGE для каждого документа

На первый взгляд проще открыть параметры нумерации страниц Word и для каждого документа установить:

```text
Начать с: 1
```

Для простого файла такой способ работает.

Однако в сложном томе появляются дополнительные разделы:

- альбомные страницы;
- А3;
- отдельные приложения;
- страницы с другими колонтитулами.

В результате логика нумерации становится зависимой от структуры разделов Word.

Более устойчивый принцип заключается в следующем:

```text
PAGE — физическая позиция страницы;
PAGEREF sN — физическая позиция начала документа;
PAGE - PAGEREF sN + 1 — номер листа внутри документа.
```

Таким образом, нумерация определяется не количеством разделов Word, а фактическим началом самостоятельного документа.

## 8. Определение количества листов документа

Для основной надписи первого листа часто требуется вывести общее количество листов документа.

Например, документ начинается с `s3`, а следующий документ — с `s4`.

Тогда количество страниц между ними определяется выражением:

```text
{ = { PAGEREF s4 } - { PAGEREF s3 } }
```

Пример:

```text
s3 = страница 12
s4 = страница 27
```

Тогда:

```text
27 - 12 = 15
```

Пояснительная записка содержит 15 листов.

Для документов схема имеет следующий вид:

```text
s1:
{ = { PAGEREF s2 } - { PAGEREF s1 } }

s2:
{ = { PAGEREF s3 } - { PAGEREF s2 } }

s3:
{ = { PAGEREF s4 } - { PAGEREF s3 } }

s4:
{ = { PAGEREF s5 } - { PAGEREF s4 } }
```

Для последнего документа следующей закладки уже нет.

В этом случае может использоваться:

```text
{ = { NUMPAGES } - { PAGEREF s5 } + 1 }
```

Здесь:

```text
NUMPAGES
```

возвращает общее количество страниц файла.

## 9. Почему SECTIONPAGES применяется с осторожностью

Поле

```text
{ SECTIONPAGES }
```

возвращает количество страниц текущего раздела Word.

Оно удобно, если:

```text
один документ СПДС = один раздел Word.
```

Но такое соответствие часто нарушается.

Например:

```text
Пояснительная записка
    раздел Word 3 — А4, книжный;
    раздел Word 4 — А3, альбомный;
    раздел Word 5 — А4, книжный.
```

С точки зрения СПДС это один документ.

С точки зрения Word — три раздела.

Следовательно:

```text
SECTIONPAGES
```

покажет количество страниц только одного из этих разделов, а не всей пояснительной записки.

Поэтому при сложной структуре надежнее определять границы документа через закладки `s1`, `s2`, `s3` и т. д.

## 10. Первый и последующие листы

Для текстовых документов СПДС оформление первого листа и последующих листов различается.

В Word это удобно реализовать через параметр:

**Особый колонтитул для первой страницы.**

Для раздела документа создаются:

- колонтитул первой страницы;
- колонтитул последующих страниц.

На первом листе размещается соответствующая основная надпись первого листа.

На последующих листах — основная надпись последующих листов.

Рамка и основная надпись обычно размещаются в колонтитулах, поскольку это позволяет:

- сохранять их положение относительно края страницы;
- исключить смещение при редактировании текста;
- использовать разные формы для первой и последующих страниц;
- независимо управлять разными разделами документа.

## 11. Связь колонтитулов разделов

После создания нового раздела Word его колонтитул по умолчанию может быть связан с предыдущим.

Для самостоятельных документов эту связь необходимо контролировать.

Используется команда:

**Конструктор колонтитулов → Как в предыдущем разделе.**

Если новый документ должен иметь собственную основную надпись, связь с предыдущим разделом отключается.

Особое внимание требуется при:

- начале нового документа;
- переходе А4 → А3;
- изменении ориентации;
- возврате А3 → А4.

Неправильно установленная связь может привести к изменению основной надписи сразу в нескольких частях тома.

## 12. Форматы А4 и А3

Один документ может включать листы разных форматов.

Например:

```text
А4 книжный
А4 книжный
А3 альбомный
А4 книжный
```

Для листа А3 создается отдельный раздел Word:

```text
Разрыв раздела
А3, альбомная ориентация
Разрыв раздела
возврат к А4
```

Закладку нового самостоятельного документа при этом создавать не требуется.

Это принципиальное различие:

```text
новый раздел Word ≠ новый документ СПДС.
```

Закладка `sN` создается только тогда, когда начинается новый самостоятельный документ.

Поэтому формула локального номера продолжает работать и после изменения формата страницы:

```text
{ = { PAGE } - { PAGEREF s3 } + 1 }
```

## 13. Основная надпись

В основную надпись рекомендуется выводить автоматическими полями как минимум:

- номер листа;
- количество листов;
- обозначение документа;
- наименование;
- другие повторяющиеся реквизиты.

Локальный номер листа для документа `s3`:

```text
{ = { PAGE } - { PAGEREF s3 } + 1 }
```

Количество листов:

```text
{ = { PAGEREF s4 } - { PAGEREF s3 } }
```

Таким образом, после добавления или удаления страниц номера пересчитываются автоматически.

## 14. Повторяющиеся реквизиты

Наименование объекта, обозначение документа, организация, стадия и другие реквизиты не рекомендуется вводить вручную во всех основных надписях.

Для этого можно использовать свойства документа Word.

Поле имеет вид:

```text
{ DOCPROPERTY "ИмяСвойства" }
```

Например:

```text
{ DOCPROPERTY "Обозначение" }
```

или:

```text
{ DOCPROPERTY "Название проекта" }
```

Тогда значение хранится в одном месте, а используется:

- на титульном листе;
- в основной надписи;
- в содержании;
- в заголовках;
- в других элементах документа.

После изменения свойства достаточно обновить поля.

## 15. Условные поля

Для изменения выводимого текста в зависимости от условия применяется поле:

```text
IF
```

Общий принцип:

```text
{ IF условие "значение 1" "значение 2" }
```

Например, поле может использоваться для:

- условного отображения реквизита;
- выбора подписи;
- скрытия значения при отсутствии данных;
- формирования различных вариантов основной надписи.

Вложенные поля создаются отдельными сочетаниями `Ctrl+F9`.

## 16. Содержание тома

Содержание тома и оглавление пояснительной записки — разные сущности.

Содержание тома должно отражать самостоятельные документы, например:

```text
Содержание тома
Состав проектной документации
Пояснительная записка
Описание технических решений
Спецификация
```

Начальный номер страницы каждого документа можно получать непосредственно из закладки.

Например:

```text
{ PAGEREF s1 }
{ PAGEREF s2 }
{ PAGEREF s3 }
{ PAGEREF s4 }
{ PAGEREF s5 }
```

При изменении объема предыдущих документов значения автоматически изменятся.

Это исключает необходимость вручную исправлять номера страниц после каждой переверстки тома.

## 17. Оглавление пояснительной записки

Оглавление пояснительной записки должно содержать только заголовки самой пояснительной записки, а не заголовки всего тома.

Для этого используется ограниченное оглавление Word.

Если пояснительная записка размечена закладкой, охватывающей требуемый диапазон, поле оглавления может быть ограничено этой закладкой.

Общий принцип:

```text
{ TOC \b имя_закладки \o "1-3" \h \z \u }
```

Например:

```text
{ TOC \b PZ \o "1-3" \h \z \u }
```

Здесь:

- `TOC` — оглавление;
- `\b PZ` — использовать только содержимое закладки `PZ`;
- `\o "1-3"` — включить уровни заголовков 1–3;
- `\h` — сформировать гиперссылки;
- `\z` — скрывать номера страниц в веб-представлении;
- `\u` — учитывать уровни структуры.

Для такой задачи удобнее использовать отдельную закладку диапазона, например:

```text
PZ
```

которая охватывает всю пояснительную записку.

Закладки `s1–s5` при этом продолжают использоваться для определения начал документов.

## 18. Стили заголовков

Автоматическое оглавление корректно работает только при структурированной разметке текста.

Для разделов следует применять стили:

```text
Заголовок 1
Заголовок 2
Заголовок 3
```

или соответствующие им специально настроенные стили документа, имеющие корректные уровни структуры.

Не рекомендуется имитировать заголовок только форматированием:

- жирным начертанием;
- увеличенным размером шрифта;
- прописными буквами.

Для Word такой абзац не является структурным заголовком и автоматически в оглавление не попадет.

## 19. Отдельная закладка для диапазона документа

Закладки `s1`, `s2`, `s3` и т. д. удобно использовать как точечные метки начала документа.

Для оглавления требуется другая задача — обозначить целый диапазон.

Поэтому могут одновременно использоваться:

```text
s3 — точка начала пояснительной записки;

PZ — диапазон всей пояснительной записки.
```

Такое разделение делает структуру документа понятнее:

- `sN` — начало самостоятельного документа;
- именованная диапазонная закладка — область действия оглавления или другой функции.

## 20. Обновление полей

После изменения документа необходимо обновлять поля.

Базовая последовательность:

```text
Ctrl+A
F9
```

Однако поля в колонтитулах Word не всегда обновляются таким способом одновременно с основным текстом.

Поэтому перед выпуском документа рекомендуется проверить отдельно:

- основной текст;
- верхние колонтитулы;
- нижние колонтитулы;
- текстовые поля;
- основные надписи;
- содержание тома;
- оглавление;
- перекрестные ссылки.

Особенно важно выполнять обновление после:

- добавления страниц;
- удаления страниц;
- изменения разрывов разделов;
- вставки А3;
- изменения структуры документов.

## 21. Проверка кодов полей

Перед выпуском документа полезно включить отображение кодов:

```text
Alt+F9
```

Это позволяет проверить, что в основной надписи действительно находится, например:

```text
{ = { PAGE } - { PAGEREF s3 } + 1 }
```

а не введенное вручную число.

После проверки:

```text
Alt+F9
```

возвращает отображение результатов полей.

## 22. Типичные ошибки

### Ошибка 1. Номер листа введен вручную

После добавления страницы дальнейшие номера становятся неправильными.

Правильно:

```text
{ = { PAGE } - { PAGEREF sN } + 1 }
```

### Ошибка 2. Для количества листов используется SECTIONPAGES

Это работает только тогда, когда весь документ занимает один раздел Word.

При наличии А3 или альбомных листов результат становится неправильным.

### Ошибка 3. Новый раздел принимается за новый документ

Раздел Word является техническим средством верстки.

Он не обязательно означает начало нового документа СПДС.

### Ошибка 4. Закладка установлена не в начале документа

Формула:

```text
PAGE - PAGEREF + 1
```

начинает давать смещенные номера.

### Ошибка 5. Колонтитул связан с предыдущим разделом

Изменение основной надписи одного документа изменяет соседний документ.

### Ошибка 6. Введены обычные фигурные скобки

Текст:

```text
{ PAGE }
```

набранный вручную, полем Word не является.

Поле создается через:

```text
Ctrl+F9
```

### Ошибка 7. Содержание тома заполняется вручную

После изменения объема любого предыдущего документа номера страниц приходится исправлять.

Правильно использовать:

```text
PAGEREF
```

### Ошибка 8. Для всего тома создается одно оглавление

В результате оглавление пояснительной записки начинает включать заголовки других документов.

Правильно ограничивать область оглавления соответствующим диапазоном.

## 23. Рекомендуемая последовательность подготовки документа

Работу целесообразно выполнять в следующем порядке:

1. Определить состав тома.
2. Определить самостоятельные документы.
3. Расставить разрывы разделов Word.
4. Создать закладки `s1`, `s2`, `s3` и далее.
5. Настроить размеры и ориентацию страниц.
6. Разместить рамки и основные надписи в колонтитулах.
7. Настроить первую и последующие страницы.
8. Отключить ненужные связи колонтитулов с предыдущими разделами.
9. Вставить вычисляемые номера листов.
10. Вставить вычисляемое количество листов.
11. Создать свойства документа для повторяющихся реквизитов.
12. Применить стили заголовков.
13. Сформировать содержание тома.
14. Сформировать локальные оглавления.
15. Обновить все поля.
16. Проверить документ в режиме отображения кодов полей.
17. Выполнить финальную проверку после преобразования в PDF.

## 24. Минимальная рабочая схема

Для документа из трех самостоятельных частей достаточно следующей структуры:

```text
s1
Документ 1
...

разрыв раздела

s2
Документ 2
...

разрыв раздела

s3
Документ 3
...
```

Номер листа документа 1:

```text
{ = { PAGE } - { PAGEREF s1 } + 1 }
```

Количество листов документа 1:

```text
{ = { PAGEREF s2 } - { PAGEREF s1 } }
```

Номер листа документа 2:

```text
{ = { PAGE } - { PAGEREF s2 } + 1 }
```

Количество листов документа 2:

```text
{ = { PAGEREF s3 } - { PAGEREF s2 } }
```

Номер листа документа 3:

```text
{ = { PAGE } - { PAGEREF s3 } + 1 }
```

Количество листов последнего документа:

```text
{ = { NUMPAGES } - { PAGEREF s3 } + 1 }
```

Это является базовой схемой, на которой можно строить значительно более сложный том.

## 25. Контрольный пример

Пусть в файле расположены следующие документы:

```text
s1 — страница 3
s2 — страница 5
s3 — страница 8
s4 — страница 23
s5 — страница 31
```

На физической странице 17 находится пояснительная записка `s3`.

Локальный номер листа:

```text
17 - 8 + 1 = 10
```

В основной надписи будет:

```text
Лист 10
```

Количество листов пояснительной записки:

```text
23 - 8 = 15
```

На первом листе может отображаться:

```text
Лист 1
Листов 15
```

При добавлении трех страниц перед пояснительной запиской:

```text
s3 = 11
PAGE текущего листа = 20
```

Формула даст:

```text
20 - 11 + 1 = 10
```

Локальный номер не изменится.

Именно это свойство делает схему устойчивой к переверстке тома.

## 26. Итоговый принцип

Документ СПДС в Word целесообразно строить не как набор вручную пронумерованных страниц, а как вычисляемую структуру.

Основные элементы этой структуры:

```text
разделы Word
        ↓
границы областей верстки

закладки s1, s2, s3...
        ↓
начала самостоятельных документов

PAGE
        ↓
текущая физическая страница

PAGEREF sN
        ↓
физическая страница начала документа

PAGE - PAGEREF sN + 1
        ↓
локальный номер листа

следующий PAGEREF - текущий PAGEREF
        ↓
количество листов документа

DOCPROPERTY
        ↓
централизованное хранение реквизитов

TOC
        ↓
автоматическое оглавление
```

В результате изменение объема текста, добавление страниц, вставка листов А3 или изменение состава тома не требуют ручного перенумерования всех последующих документов.

После корректной первоначальной разметки Word самостоятельно рассчитывает номера листов, количество листов, номера страниц в содержании и другие зависимые реквизиты.

Такой подход позволяет использовать Microsoft Word как полноценную среду подготовки структурированной документации СПДС, сохраняя управляемость документа даже при сложной компоновке тома.
