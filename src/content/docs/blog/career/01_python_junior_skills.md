Для трудоустройства на позицию Junior Python Developer необходимы базовые навыки программирования, работы с инструментами разработки и выполнения прикладных задач.

## Python

- Типы данных, выражения, условия, циклы и функции.
- Коллекции: списки, словари, кортежи, множества.
- Исключения, контекстные менеджеры, модули и пакеты.
- Основы ООП: классы, наследование, композиция, полиморфизм.
- Работа с TXT, CSV, JSON, XML и XLSX.
- Аннотации типов, стандартная библиотека, отладка.

## Среда разработки

- PyCharm или Visual Studio Code.
- `pip`, `venv`, `requirements.txt`, `pyproject.toml`.
- Git: коммиты, ветки, слияния, запросы на включение изменений.
- Основы Linux и командной строки.

## Базы данных и веб-разработка

- SQL: `SELECT`, `JOIN`, `GROUP BY`, `INSERT`, `UPDATE`, `DELETE`.
- PostgreSQL или SQLite; ключи, индексы, транзакции.
- HTTP, REST API, JSON, аутентификация и авторизация.
- Один фреймворк на уверенном уровне: Flask, Django или FastAPI.

## Тестирование и качество

- `pytest` или `unittest`, модульные и интеграционные тесты.
- Ruff или Black, обработка ошибок, читаемость кода.
- Базовые алгоритмы и оценка сложности Big O.

## Дополнительные направления

- `pandas`, `numpy`, Matplotlib для обработки данных.
- `requests` или `httpx` для интеграции с API.
- Jira и Confluence для командной работы.

## Критерии готовности

Кандидат способен самостоятельно разработать небольшое приложение, подключить базу данных, реализовать API, написать тесты, опубликовать исходный код в Git и объяснить архитектуру решения.
