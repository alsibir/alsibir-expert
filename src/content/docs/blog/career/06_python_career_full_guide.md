## 1. Введение

Python применяется для веб-разработки, автоматизации, интеграции информационных систем и обработки данных. Для первой работы важны не только знания синтаксиса, но и умение создать, протестировать и представить программное решение.

## 2. Основы Python

Необходимо освоить типы данных, условия, циклы, функции, коллекции, обработку исключений, файлы, модули, ООП, аннотации типов и стандартную библиотеку. Для обмена данными востребованы CSV, JSON, XML и XLSX.

## 3. Среда разработки

Рекомендуются PyCharm или VS Code, `pip`, `venv`, `pyproject.toml`, Git, GitHub или GitLab. Требуется уметь пользоваться отладчиком, ветками и запросами на включение изменений.

## 4. SQL и базы данных

Следует знать PostgreSQL или SQLite, запросы `SELECT`, `INSERT`, `UPDATE`, `DELETE`, объединения таблиц, агрегирование, индексы, ключи и транзакции. Полезно освоить SQLAlchemy.

## 5. Backend и API

Необходимы знания HTTP/HTTPS, методов GET, POST, PUT, PATCH, DELETE, кодов ответа, JSON, REST, аутентификации и авторизации. Для практики достаточно одного фреймворка — Flask, Django или FastAPI. Для внешних запросов применяются `requests` и `httpx`.

## 6. Обработка данных

Библиотеки pandas, NumPy и Matplotlib позволяют очищать, преобразовывать и визуализировать данные. Excel, Power Query и Power BI могут дополнять навыки Python-разработчика в задачах автоматизации отчётности.

## 7. Тестирование

Базовые компетенции: `pytest`, `unittest`, модульные и интеграционные тесты, обработка ошибок, Ruff, Black и статическая проверка типов.

## 8. Алгоритмы

Следует понимать списки, словари, множества, стеки, очереди, деревья, графы, поиск, сортировку, рекурсию и оценку сложности Big O.

## 9. Инструменты командной работы

Jira — управление задачами, дефектами, спринтами и процессами разработки. Confluence — управление знаниями, совместная работа с технической и проектной документацией. Общая категория: средства управления проектами и совместной работы.

## 10. Образование

**РАНХиГС:** Федеральное государственное бюджетное образовательное учреждение высшего образования «Российская академия народного хозяйства и государственной службы при Президенте Российской Федерации».

**Институт:** Институт экономики, математики и информационных технологий (ЭМИТ).

**Подготовка:** бакалавриат, «Бизнес-информатика», программа «Информационные системы в бизнесе и логистике», Москва, 2018–2023.

**Профильные области:** программирование, базы данных, архитектура информационных систем, системный анализ, моделирование бизнес-процессов, логистика, управление ИТ-проектами, анализ данных, информационная безопасность. Точные названия дисциплин подлежат сверке с приложением к диплому.

## 11. Практический опыт

При отсутствии коммерческого стажа допустимо описывать только реально выполненные учебные и самостоятельные проекты:

- Система управления логистическими процессами: Python, Flask, PostgreSQL.
- Анализ продаж: Python, pandas, NumPy, Matplotlib.
- Прототип CRM: Python, SQL, CRUD-операции.
- Моделирование бизнес-процессов: BPMN и анализ требований.

Эти варианты являются примерами, а не утверждением о фактически выполненных работах выпускника.

## 12. Практика и стажировки

Для реальной практики указать организацию, период, роль, личный вклад и результат. Возможные задачи: SQL-запросы, автоматизация отчётов, тестирование модулей, подготовка документации. Вымышленные стажировки включать нельзя.

## 13. Портфолио

Рекомендуется подготовить 2–3 завершённых проекта. Для каждого репозитория нужны исходный код, README, инструкция запуска, описание функций, примеры данных и тесты. Хорошие варианты: веб-приложение с API, скрипт обработки Excel, система учёта заказов.

## 14. Резюме

**Должность:** Junior Python Developer / Младший Python-разработчик.

**Профессиональный профиль:** выпускник РАНХиГС по направлению «Бизнес-информатика», обладающий подтверждёнными знаниями Python, SQL, REST API и Git; заинтересован в серверной разработке, интеграции и автоматизации бизнес-процессов.

В резюме следует указывать только реально освоенные технологии, выполненные проекты и пройденные курсы.

## 15. Техническое собеседование

Повторить изменяемые и неизменяемые объекты, списки и кортежи, ООП, исключения, SQL JOIN, GROUP BY, транзакции, REST API, HTTP-коды, аутентификацию и тестирование. Практиковать короткие задачи на Python и SQL, уметь объяснять архитектуру портфолио.

## 17. Критерии готовности

Кандидат может самостоятельно разработать небольшое приложение, организовать структуру проекта, использовать Git, подключить БД, создать API, написать тесты, устранить ошибки и объяснить принятое решение.

## 18. Заключение

Главный критерий готовности к трудоустройству — способность создать, протестировать, документировать и представить работающее программное решение. Профильное образование в области бизнес-информатики дополнительно помогает понимать бизнес-задачи и требования к информационным системам.
