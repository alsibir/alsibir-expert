| Термин | Краткое определение |
|---|---|
| ТЗ | Техническое задание; договорное и проектное описание требований в установленной форме |
| ПМИ | Программа и методика испытаний; условия, методы и ожидаемые результаты проверок |
| ЕСПД | Единая система программной документации |
| ГОСТ 34 | Комплекс стандартов для автоматизированных систем (применимость проверяется по задаче) |
| UML | Язык моделирования структуры и поведения систем |
| BPMN | Нотация моделирования бизнес-процессов |
| API | Программный интерфейс взаимодействия компонентов |
| Трассируемость | Установление проверяемых связей между исходными требованиями, решениями и испытаниями |

Сокращения следует раскрывать при первом использовании и определять в глоссарии конкретного документа.
